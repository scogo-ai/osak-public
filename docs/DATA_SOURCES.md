# Source rights and attribution

OSAK's Apache-2.0 license covers its code. Each source supplies its own data terms. Preserve the source, retrieval time, field, license and original URL when exporting facts. A public feed, a TLP marking or possession of credentials alone does not establish a license to redistribute a vendor's material. Review this register whenever a publisher changes its terms.

Connectors use supported publisher APIs, data releases and RSS feeds. RSS can identify new advisories and link to the publisher's authoritative records. The worker stores structured facts from approved sources so matching and dataset exports can use the same local evidence. NVD supplies CPE and CVSS enrichment. Vendor and CVE Program records supply software version applicability.

## Future sources

Palo Alto, Juniper, HPE Aruba, Zscaler, CERT-Bund, NCSC-NL, OSV and GHSA each need a source-specific license review and a recorded attribution before activation. Keep Vulners and NotCVE disabled by default. Operators who license either paid source must check their own entitlements. Exclude paid records from the public service and exports.
