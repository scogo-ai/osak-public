# Contributing

Use Python 3.12 and install the locked dependencies with `uv sync --locked`. See AGENTS.md for the test commands. Keep each pull request focused and describe which inputs and expected outputs you verified.

Changes to matching need independent vendor evidence across affected, fixed, incomparable and unknown inputs. Supply the source URL, observation date and minimal facts needed to reproduce the expectation. Check the publisher's redistribution terms before committing a fixture. Use synthetic asset references in tests.

See docs/ADDING_AN_OEM.md before adding a connector. Dependencies and contributions must permit distribution of the code under Apache-2.0.
