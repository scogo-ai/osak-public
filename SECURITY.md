# Reporting a security problem

Use the repository's **Security → Report a vulnerability** action when private vulnerability reporting is enabled. If it is unavailable, contact Scogo.AI through its company contact channel and ask for a private security contact before sending details.

Identify the affected release, interface, impact and a sanitized description of the issue. Keep credentials, user identities and real asset inventories out of reports and public issues. For an exposed OSAK key, rotate or revoke it promptly. Report upstream advisory corrections to their original publisher and include the upstream reference when requesting a data refresh here.
