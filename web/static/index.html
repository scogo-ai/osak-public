A small request

Ask about the device, not the whole world.

Send only what is needed for this check. The service returns structured facts; it never adds your inventory to the advisory store.

POST /api/v1/match
curl -X POST https://osak.lab.scogo.ai/api/v1/match \
  -H 'X-API-Key: osak_live_…' \
  -d '{"assets":[{"asset_ref":"edge-01","vendor":"fortinet","os":"fortios","version":"7.2.5"}]}'
✓Structured response
{
  "verdict": "unknown",
  "reasons": ["version range needs review"],
  "provenance": ["Fortinet PSIRT"]
}
